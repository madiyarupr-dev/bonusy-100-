# Meta Ads → Google Таблица

Скрипт для Google Таблицы: каждый день забирает статистику из рекламного кабинета Facebook/Instagram (Meta)
и складывает в таблицу. Работает внутри Google, отдельный сервер не нужен, платных коннекторов тоже.

**Что попадает в таблицу** (по дням и по каждому объявлению): расход, показы, охват, клики, клики по ссылке,
лиды, CPL (цена лида), CTR, CPC, CPM. Лист «Сводка» даёт итоги по кампаниям за выбранный период.

## Установка (10 минут)

1. Создайте новую Google Таблицу.
2. **Расширения → Apps Script**. Удалите содержимое редактора, вставьте весь файл [`Code.gs`](Code.gs), нажмите «Сохранить».
3. Обновите вкладку с таблицей: появится меню **Meta Ads**.
4. **Meta Ads → 1. Подготовить таблицу.** Google попросит разрешения: скрипту нужен доступ к этой таблице, к внешним
   запросам (чтобы обращаться к Meta) и к триггерам (чтобы обновляться по расписанию). Если появится
   «Google не проверил это приложение», выберите «Дополнительные настройки → Перейти на страницу…». Скрипт ваш, он
   лежит в вашем аккаунте.
5. На листе **«Настройки»** впишите ID рекламного кабинета (`act_1234567890`; он виден в Ads Manager в списке аккаунтов).
6. Получите токен Meta (раздел ниже) и введите его: **Meta Ads → 2. Ввести токен Meta**. Токен хранится в настройках
   скрипта, а не в таблице.
7. **Meta Ads → 3. Проверить подключение.** Должно показать название кабинета, валюту и часовой пояс.
8. **Meta Ads → Обновить данные.** Первая загрузка берёт 90 дней (меняется в настройках).
9. **Meta Ads → Включить ежедневное обновление.**

Статус последнего запуска (время, «OK» или ошибка, период) всегда виден внизу листа «Настройки».

## Токен Meta

Нужен токен с разрешением **`ads_read`** и доступом к вашему рекламному кабинету. Надёжнее всего токен
**системного пользователя** (Бизнес-настройки → Пользователи → Системные пользователи): ему назначается
рекламный аккаунт, а токен можно сделать бессрочным. Для него нужно приложение в Meta for Developers, привязанное к
бизнесу. Для быстрой проверки подойдёт токен из Graph API Explorer, но он живёт считанные часы.

Интерфейс Meta часто меняется, поэтому сверяйтесь с их документацией «Marketing API → Insights».
**Не отправляйте токен в чаты и письма.** Он даёт доступ к статистике кабинета. Вводите его только через меню таблицы.

## Как устроены листы

| Лист | Что это |
|---|---|
| **Настройки** | Аккаунты, что считать лидом, сколько дней перезаписывать, статус запуска. |
| **Сводка** | Итого и по кампаниям за период. Даты в `B2` и `B3` можно менять. Считается формулами по листу Data. |
| **Data** | Сырые данные: одна строка = день × объявление. Лист обновляется скриптом: **не сортируйте и не правьте его вручную**. Анализ стройте на других листах или подключайте Data к Looker Studio. |

### Как обновляются данные

Meta дописывает конверсии задним числом, поэтому при каждом запуске скрипт заново загружает последние N дней
(по умолчанию 7) и **заменяет** ими строки за эти дни. Дублей не будет, а история старше N дней не меняется.
Если загрузка по одному из аккаунтов упала, его старые строки остаются на месте, остальные аккаунты обновятся.
Чтобы подтянуть более раннюю историю или историю **нового аккаунта**, который вы добавили позже, выберите
«Загрузить историю с даты…»: при обычном обновлении берутся только последние N дней.

### Что считать лидом

В настройке «Что считать лидом» указывается `action_type` из Meta. Указывайте **один** тип, иначе лиды удвоятся.

| Откуда лиды | action_type |
|---|---|
| Все лиды (форма Meta и сайт), по умолчанию | `lead` |
| Только формы Meta | `onsite_conversion.lead_grouped` |
| Только сайт (пиксель) | `offsite_conversion.fb_pixel_lead` |
| Переписки (WhatsApp, Direct, Messenger) | `onsite_conversion.messaging_conversation_started_7d` |

Если лидов 0, а в Ads Manager они есть, попробуйте другой тип из таблицы. Сверьте итоги за один день с Ads Manager.
Различия бывают из-за окна атрибуции и часового пояса кабинета.

## Нюансы

- **Охват не складывается по дням.** Один человек, увиденный в два дня, считается дважды, поэтому в «Сводке» охвата нет.
- **Сегодняшний день** по умолчанию не загружается (данные неполные). Включается в настройках.
- **Доступ к таблице = доступ к токену.** Любой, кто может *редактировать* таблицу, может открыть код и прочитать токен.
  Остальным давайте доступ «Просмотр».
- Триггер работает от имени того, кто его включил. Если у этого человека пропадёт доступ к кабинету, обновления
  начнут падать, и это будет видно в статусе.
- В таблице Google до 10 млн ячеек. Лист Data занимает 20 колонок, то есть примерно 500 тыс. строк. Для очень
  больших кабинетов (тысячи объявлений) лучше BigQuery.
- Один запуск в Google Apps Script ограничен 6 минутами. Данные записываются в конце, поэтому при превышении лимита
  таблица остаётся целой, но не обновляется. Для очень больших кабинетов загружайте историю частями
  («Загрузить историю с даты…» с более поздней даты).
- Версия API задана в начале `Code.gs` (`API_VERSION`). Если Meta снимет её с поддержки, поменяйте на актуальную.

## Тесты

```
node meta-ads-sheets/test/run.js
```

Зависимостей нет. Код грузится в изолированный контекст, а Google-сервисы заменены имитациями, которые повторяют
ограничения настоящих Sheets: выход за границы листа, превращение длинных ID в числа, часовые пояса.
Тесты покрывают разбор настроек, запросы и пагинацию Meta, повторы при лимитах, перезапись окна данных, несколько
аккаунтов, формулы сводки и триггеры.

**Чего тесты не доказывают:** они не обращались к настоящему Meta API и не запускались в настоящих Google Sheets. Ответы
Meta в тестах составлены по документации. Поэтому после установки сверьте первые цифры с Ads Manager.
