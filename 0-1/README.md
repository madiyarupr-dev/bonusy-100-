# 0-1

**Продукт, который помогает правильно внедрить ИИ в бизнес — от нуля до первого измеримого результата.**

ИИ в компании — это не бот и не подписка, а **контекст + правила + исполнители + контроль, привязанные к целям владельца в цифрах.**

Владельцы продукта: Нурдаулет и Мадияр. Статус: архитектура в работе, v0.1 (09.10.2026).

## Что здесь

| Файл | Что внутри |
|---|---|
| [ARCHITECTURE.md](ARCHITECTURE.md) | принципы, 7 слоёв системы, путь внедрения из 8 этапов, матрица прав ИИ, метрики, типовые ошибки |
| [decisions/](decisions/) | принятые решения по продукту (DEC-NNN) |
| [OPEN_QUESTIONS.md](OPEN_QUESTIONS.md) | что ещё нужно решить до первых пилотов |

## Метки

- **ФАКТ** — проверено на практике.
- **ИНТЕРПРЕТАЦИЯ** — вывод из фактов.
- **ГИПОТЕЗА** — нужно проверить на пилотах.

## Правило репозитория

У каждого факта одно место. Решение, которое приняли, попадает в `decisions/`, а не остаётся в чате.
